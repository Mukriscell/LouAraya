# Gestión de stock · 25 de octubre de 2026

## Uso del administrador

1. Abrir Piezas y pulsar **Gestionar stock** en el producto.
2. Elegir **Entrada**, indicar las unidades recibidas y pulsar **Registrar entrada**.
3. Para una venta sin solicitud asociada, elegir **Venta directa**, indicar las unidades vendidas y pulsar **Registrar venta directa**.
4. Para pérdidas, daños u otras salidas, elegir **Retiro**. Se puede dejar una observación en cada movimiento.

Por ejemplo, una entrada de 10 unidades y una venta directa de 3 deja 7 unidades en bodega. El saldo también se muestra en la lista de productos y en el editor de la ficha. El historial conserva cantidad, saldo posterior, fecha, observación y administrador responsable.

## Solicitudes y ventas

- Entregar una compra o reserva descuenta **una unidad** de su producto, dentro de la misma transacción que actualiza el estado y genera el aviso.
- Confirmar una solicitud no reserva ni descuenta existencias.
- Si no hay stock, se rechaza la entrega y se conserva el estado anterior. El detalle incluye un acceso a la bodega para registrar una entrada y volver.
- Repetir la entrega, o cambiar el estado y volver a Entregado, no duplica el descuento.
- Las cotizaciones personalizadas no consumen la pieza usada como referencia.
- Cambiar el estado después de la entrega no repone stock. Una devolución se registra como una entrada.
- Las ventas directas son independientes de las solicitudes; no se debe registrar otra venta directa para una solicitud cuyo descuento se hará al entregarla.

Cada solicitud existente corresponde a una pieza. Las ventas directas permiten registrar varias unidades a la vez. La entrega no procesa pagos.

## Datos existentes y límites

La migración de Room 7 a 8 conserva los datos actuales. Los productos empiezan con cero unidades para que el administrador ingrese el conteo real. Las entregas anteriores se identifican como históricas y no generan descuentos retroactivos, aunque se vuelva a cambiar su estado.

Solo el administrador puede modificar existencias o consultar el historial. Las cantidades deben ser enteras positivas; no se permite stock negativo ni desbordamiento. Editar una ficha de producto conserva el stock actual.

La bodega pertenece a esta instalación Android, igual que el resto de los datos del proyecto. No se sincroniza entre teléfonos.
